# Sentia Intelligence from Conversations — Frontend 0.3.39

Frontend estático para GitHub Pages.

## Publicación

1. Sube **todo el contenido de este repositorio** a GitHub.
2. En GitHub Pages publica desde `main` / raíz.
3. Abre Sentia y ve a **Configuración → Backend seguro**.
4. Introduce la URL HTTPS del repositorio backend de Sentia y pulsa **Probar conexión**.

## Arquitectura

GitHub Pages → JavaScript/IndexedDB → Backend HTTPS → Cohere / Meta / Instagram / X / TikTok / YouTube / LinkedIn / GA4.

El frontend no contiene API keys ni OAuth secrets.
