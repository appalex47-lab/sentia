Entrada universal

Ingesta manual de conversaciones

LOCAL-FIRST

Usa esta entrada para WhatsApp, llamadas y otras conversaciones. El idioma operativo de Sentia es español: WhatsApp y transcripciones de llamadas se analizan en español por defecto. También puedes importar otros idiomas y traducirlos con Cohere.

1. Fuente

2. Idioma

Por defecto: es (español).

Si existe texto_traducido, Sentia analiza esa versión y conserva el original para trazabilidad.

3. Audio de llamada (opcional)

Para llamadas, puedes cargar directamente un audio en español de hasta 25 MB.

4. Archivo

Selecciona un archivo para comenzar.

Cómo manejar WhatsApp y llamadas

  • WhatsApp: exporta el chat como TXT sin necesidad de cargarlo a un servicio externo.
  • Llamadas: puedes cargar directamente MP3, WAV, FLAC, OGG o MPEG de hasta 25 MB; Cohere Transcribe recibe el idioma es y devuelve texto para el pipeline.
  • Traducción: puedes entregar original + texto_traducido; Sentia analiza la traducción y conserva ambos.
  • Privacidad: los archivos se procesan localmente mediante Python y no se suben a un proveedor por esta ingesta.

CREDENCIALES SEGURAS

Configura aquí identificadores, preferencias y permisos. Las claves, client secrets y tokens se gestionan exclusivamente mediante el conector Python correspondiente.

Orquestación multi-fuente

Sincronización manual disponible. La sincronización automática es opcional y se ejecuta mientras la app esté abierta, según la frecuencia seleccionada. La programación se guarda en IndexedDB.

La frescura es una señal operativa: fresh = dentro de la frecuencia, warning = superó una frecuencia, stale = superó dos, error = último intento fallido, never = aún no existe una sincronización exitosa.

Cómo interpretar la plataforma

Sentimiento
Polaridad producida por el modelo de sentimiento.
Confianza
Confianza del modelo; no equivale al score de negocio.
Score
Resultado matemático determinístico de las reglas configuradas.
Severidad
Nivel derivado del score; no es sinónimo de sentimiento.
Calidad
Evaluación de la integridad y utilidad del dato de entrada.
IA
Cohere aporta interpretación generativa; no define los KPIs.
